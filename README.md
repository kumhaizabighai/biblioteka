# Бібліотека — читайте перед тим, як щось міняти

## Що тут є

```
.nojekyll             — вимикає обробку GitHub Pages (не чіпати)
index.html            — сама сторінка (не чіпати)
manifest.json         — налаштування PWA (не чіпати)
sw.js                 — офлайн-кешування (не чіпати)
css/style.css         — вигляд (можна тонко підлаштувати кольори)
js/app.js             — логіка застосунку (не чіпати)
books/books.json       — ЄДИНИЙ файл, який тобі треба редагувати, щоб додати книжку
icons/                 — іконки для «Додати на головний екран»
```

## Як розмістити на GitHub Pages

**Один раз, при налаштуванні:**

1. На github.com → **New repository** → назви, наприклад `biblioteka` → **Public** → Create.
2. Відкрий репозиторій → **Add file → Upload files** → перетягни туди весь **вміст** цієї папки (включно з файлом `.nojekyll` — він може виглядати як прихований, увімкни показ прихованих файлів у своєму провіднику, якщо не бачиш його) — саме вміст, а не саму папку `library` як одну одиницю.
3. Внизу сторінки — **Commit changes**.
4. **Settings → Pages** (у лівому меню) → у "Build and deployment" обери **Source: Deploy from a branch**, гілка **main**, папка **/(root)** → **Save**.
5. Через 1–2 хвилини GitHub покаже посилання виду:
   `https://твій-нікнейм.github.io/biblioteka/`
6. Відкрий це посилання на планшеті → в браузері обери «Додати на головний екран».

## Як додати нову книжку (після налаштування — назавжди так)

1. У репозиторії відкрий `books/books.json`.
2. Натисни іконку олівця (**Edit**) у правому верхньому куті файлу.
3. Додай новий блок у масив `"books"`, наприклад:

```json
{
  "id": "kotyhoroshko",
  "title": "Котигорошко",
  "category": "Класика",
  "pages": [
    { "text": "Перша сторінка тексту..." },
    { "text": "Друга сторінка тексту..." }
  ]
}
```

- `id` — коротке унікальне слово латиницею, без пробілів.
- `category` — одна з: `Класика`, `Пригоди`, `Тварини`, `Наука і природа`, `Україна` (або нова — просто додай її і до списку `"categories"` на початку файлу, і з'явиться нова полиця).
- `pages` — кожен об'єкт `{"text": "..."}` — одна сторінка. Розбивай текст на невеликі шматки (кілька речень), а не суцільним полотном.

4. Внизу — **Commit changes** прямо з веб-редактора.

Сайт оновиться сам за хвилину-дві. Код застосунку більше ніколи не чіпаєш — і кожна зміна автоматично зберігається в історії GitHub, тож завжди можна відкотитись, якщо десь помилишся в JSON.

## Обкладинки

Зараз генеруються самим застосунком (кольоровий фон + назва). Якщо захочеш підставити справжню ілюстрацію — скажи, додамо підтримку поля `"cover": "books/covers/kotyhoroshko.jpg"` per-книжка.

## Приватність

Публічний репозиторій означає, що вміст (код і тексти казок) технічно доступний будь-кому, хто знайде посилання чи сам репозиторій. Для народних казок це не проблема. Якщо колись захочеш додати щось приватне — знадобиться платний GitHub-план для приватного репозиторію з увімкненими Pages.

## Локальна перевірка (необов'язково)

```
cd library
python3 -m http.server 8000
```

і відкрити `http://localhost:8000`.

## Що НЕ реалізовано навмисно (за задумом v1)

Немає акаунтів, статистики, звуку, ШІ-функцій, гейміфікації. «Прочитані книжки» — локальна позначка в браузері конкретного пристрою (не синхронізується між пристроями чи браузерами).
