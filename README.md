# Бібліотека — читайте файл перед тим, як щось міняти

## Що тут є

```
index.html          — сама сторінка (не чіпати)
manifest.json        — налаштування PWA (не чіпати)
sw.js                 — офлайн-кешування (не чіпати)
css/style.css         — вигляд (можна тонко підлаштувати кольори)
js/app.js             — логіка застосунку (не чіпати)
books/books.json       — ЄДИНИЙ файл, який тобі треба редагувати, щоб додати книжку
icons/                 — іконки для «Додати на головний екран»
```

## Як додати нову книжку

Відкрий `books/books.json` у звичайному текстовому редакторі і додай новий блок у масив `"books"`, наприклад:

```json
{
  "id": "kotyhoroshko",
  "title": "Котигорошко",
  "category": "Класика",
  "pages": [
    { "text": "Перша сторінка тексту..." },
    { "text": "Друга сторінка тексту..." }
  ]
}
```

- `id` — коротке унікальне слово латиницею, без пробілів.
- `category` — одна з: `Класика`, `Пригоди`, `Тварини`, `Наука і природа`, `Україна` (або нова назва — вона автоматично з'явиться як нова полиця, якщо додати її й до списку `"categories"` на початку файлу).
- `pages` — кожен об'єкт `{"text": "..."}` це одна сторінка. Розбивай текст на невеликі шматки (кілька речень), а не суцільним полотном.

Код застосунку після цього чіпати не треба — нова книжка й нова полиця з'являться самі.

## Обкладинки

Зараз обкладинки генеруються самим застосунком (кольоровий фон + назва). Якщо захочеш підставити справжню ілюстрацію — скажи, і додамо підтримку картинки per-книжка (наприклад, поле `"cover": "books/covers/kotyhoroshko.jpg"`).

## Як перевірити локально

Найпростіше — відкрити папку в будь-якому найпростішому локальному сервері (подвійний клік на `index.html` може не спрацювати через обмеження браузера на `fetch` локальних файлів). Якщо є Python:

```
cd library
python3 -m http.server 8000
```

і відкрити `http://localhost:8000` у браузері.

## Як розмістити на Hostinger

1. File Manager → `public_html/biblioteka` (або інша назва папки).
2. Завантажити всю цю папку (усі файли й підпапки) саме в такій структурі.
3. Відкрити `serolmetal.pt/biblioteka/` (чи яку папку обереш) — і на планшеті/телефоні можна одразу «Додати на головний екран».

## Що НЕ реалізовано навмисно (за задумом v1)

Немає акаунтів, статистики, звуку, ШІ-функцій, гейміфікації. «Прочитані книжки» — це локальна позначка в браузері конкретного пристрою (не синхронізується між пристроями).
